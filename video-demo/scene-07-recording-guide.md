# Scene 07 — Human Gate Recording Guide

## Duration
4:00–5:00 (60 seconds)

## Visual Target
TuntasUMKM Dashboard (browser)

## What to Show

### Flow
1. Order ORD-20260927-35BD8E visible in approval queue
2. Click order to select
3. Click "Approve" button
4. Confirmation dialog appears
5. Review consequences
6. Click "Confirm Approval"

## Browser Setup
- URL: http://127.0.0.1:3000
- Browser: Chrome/Edge (clean profile)
- Window size: 1920×1080
- Zoom: 100%

## What Must Be Visible
- Order in approval queue
- Order details (product, SKU, quantity, total)
- Approve button
- Confirmation dialog with consequences
- Confirm Approval button

## What Must Be Hidden
- Other browser tabs
- Bookmarks bar
- Password manager overlays
- Personal data in other orders

## Narration
> "Di sini keputusan transaksional berpindah ke manusia. Agent tidak memiliki capability untuk melakukan approval.
>
> Lihat konsekuensinya — approval ini akan memproses order, dan setelah approval backend menjalankan efek bisnis seperti deduction stock dan notification.
>
> Confirm Approval."

## Recording Steps
1. Navigate to dashboard
2. Wait for page load
3. Click on order ORD-20260927-35BD8E in queue
4. Wait for order detail to load
5. Click "Approve" button
6. Wait for confirmation dialog
7. Pause briefly (let audience read consequences)
8. Click "Confirm Approval"
9. Wait for state change

## Safety Check
- [ ] Clean browser (no other tabs)
- [ ] No password manager
- [ ] No personal data visible
- [ ] Dashboard fully loaded
- [ ] Order visible in queue
