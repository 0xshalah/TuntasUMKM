# Scene 04 — User Intent Recording Guide

## Duration
1:30–2:00 (30 seconds)

## Visual Target
Hermes terminal with user input

## What to Show

### Input
```
Saya mau pesan Sarung Tenun Samarinda 1 pcs
```

## Terminal Setup
- Same terminal as Scene 03
- Clear screen before recording
- Show prompt clearly

## Recording Steps
1. Clear terminal
2. Type the prompt character by character (or paste with typing effect)
3. Press Enter
4. Wait for agent to start processing

## What Must Be Visible
- Full prompt text: "Saya mau pesan Sarung Tenun Samarinda 1 pcs"
- Cursor/prompt indicator

## What Must Be Hidden
- Previous terminal history
- Any sensitive data

## Narration
> "User mau pesan Sarung Tenun Samarinda 1 pcs. Kita kirim ini ke Hermes Agent."

## Safety Check
- [ ] Clean terminal
- [ ] No previous sensitive commands
- [ ] Prompt text clearly readable
